# 할인 끝나면 내 요금은?

휴대폰(알뜰폰 포함) 요금 할인이 **언제 끝나고, 그 뒤 매달 얼마를 내는지** 계산하는 웹 도구입니다.

👉 **https://Raonkim.github.io/promo-end-calc/**

## 왜 만들었나

알뜰폰 요금제는 "N개월 할인 후 정상 요금" 구조가 많습니다. 그런데 사람들이 실제로 헷갈리는 건 세 가지입니다.

1. **"N개월 할인"이 정확히 언제 끝나는지 헷갈립니다.** 개통한 달을 1개월째로 세는지, 다음 달부터 세는지, 날짜로 세는지에 따라 같은 "6개월 할인"도 끝나는 날이 한 달 가까이 달라집니다. 이 도구는 어느 방식이 맞는지 단정하지 않고 세 가지를 모두 계산합니다.
2. **할인이 끝나는 날을 잊습니다.** 정부도 2026년 9월에 "요금제 유지기간 종료 알림"을 이동통신 3사 대상으로 추진하기로 했지만([블로터](https://www.bloter.net/news/articleView.html?idxno=673823)), 알뜰폰에도 적용되는지는 아직 알 수 없습니다.
3. **데이터를 다 쓴 뒤 속도(예: 1Mbps)로 무엇을 할 수 있는지** 감이 오지 않습니다.

이 도구는 요금제를 비교하거나 추천하지 않습니다. **사용자가 계약서에 적힌 값을 넣으면** 세 가지 방식으로 할인 종료일을 모두 계산해 보여 주고, 달력 알림 파일(.ics)을 만들어 줍니다.

## 하는 것 / 하지 않는 것

| 한다 | 하지 않는다 |
|---|---|
| 할인 종료일 계산(세 가지 세는 방법), 월별 예상 청구액(일할 근사), 달력 알림 파일 | 요금제 데이터 수집·비교·순위·추천 |
| 소진 후 속도로 볼 수 있는 유튜브 화질 (YouTube 고객센터 권장 속도 기준) | 특정 회사 이름 노출, 제휴·광고 링크 |
| 계약서 확인 체크리스트 | 입력값 저장·전송 (모두 브라우저 안에서 계산) |

**요금제 데이터를 넣지 않은 이유.** 시장 전체 알뜰폰 요금제를 다시 배포할 수 있는 공식 출처가 없습니다. 알뜰폰허브([이용약관](https://www.mvnohub.kr/policy/terms.do))·스마트초이스([이용약관](https://www.smartchoice.or.kr/smc/etc/useRule.do)) 약관은 사전 승낙 없는 복제·유통을 금지하고, 재배포가 허용된 공공데이터([우체국 알뜰폰 요금제 조회 서비스](https://www.data.go.kr/data/15075270/openapi.do))는 우체국 판매분만 담고 있으며 할인 종료 후 요금 필드가 없습니다. 그래서 데이터를 모으는 대신 **사용자 자신의 계약**을 계산하는 쪽을 택했습니다.

## 보안·개인정보

- 위협 모델: 입력값(요금·개통일)이 제3자에게 새거나, 조작된 링크로 다른 값이 미리 채워지는 것.
- 서버가 없습니다(GitHub Pages 정적 파일). 분석 스크립트·외부 폰트·CDN을 쓰지 않습니다.
- CSP `default-src 'none'; script-src 'self'; style-src 'self'`. 외부로 나가는 요청이 없습니다.
- URL 파라미터로 값을 미리 채우는 기능을 넣지 않았습니다. 사용자 입력은 `textContent`로만 화면에 씁니다.
- 의존성 0개.

## 계산 규칙

- **개통한 달을 1개월째로**: 개통월 + (N−1)개월의 말일까지 할인
- **다음 달부터 N개월**: 개통월 + N개월의 말일까지 할인
- **날짜로 N개월**: 민법 제160조처럼 N개월 뒤 같은 날짜의 전날까지. 같은 날짜가 없으면 그 달 말일까지
- 월 청구액 = (할인 요금 × 할인 일수 + 정상 요금 × 정상 일수) ÷ 그 달 일수, 원 단위 반올림. 부가서비스·단말기 할부·절사 규칙은 반영하지 않습니다.

**계산 결과보다 계약서와 회사 이용약관이 우선합니다.**
